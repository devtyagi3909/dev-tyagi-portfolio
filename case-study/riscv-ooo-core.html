Out-of-Order Superscalar RISC-V Processor

1st Place + Special Jury Award — SanDisk Hardware Hackathon (100+ teams)

The Challenge

Design a fully compliant RV32I processor that executes instructions out-of-order using Tomasulo's Algorithm, with speculative execution and precise exception handling.

The core implements a robust out-of-order microarchitecture centered around Tomasulo's Algorithm. Instructions are fetched, decoded, and issued to reservation stations, bypassing register bottlenecks. A Reorder Buffer (ROO) ensures instructions commit in-order to maintain precise architectural state, while a Common Data Bus (CDB) broadcasts results to dependent instructions instantly. Speculative execution is supported by advanced branch prediction, enabling deep pipelines without significant stalling.

The Hard Bug

During verification, we encountered a subtle RAW (Read-After-Write) hazard that only manifested under back-to-back dependent ALU instructions when the ROB was nearly full. The scoreboard was correctly tracking in-flight instructions, but the CDB broadcast timing had a 1-cycle race condition with the reservation station wakeup logic.

This edge case was isolated using constrained-random UVM stimulus specifically targeting ROB pressure scenarios. The fix required a direct forwarding bypass from the CDB broadcast stage directly to the reservation station comparators in the same cycle, resolving the race condition without impacting critical path delay.

Verification

The processor was verified using a robust UVM testbench architecture. We achieved >95% functional coverage utilizing constrained-random stimulus to stress-test complex hazard scenarios, forwarding paths, and pipeline flushes. SVA (SystemVerilog Assertions) were deployed on the AXI interface and internally to enforce critical pipeline invariants throughout the execution flow.

Results

The finalized design achieved 250 MHz post-synthesis on an UltraScale+ FPGA platform. It demonstrated full RISC-V ISA compliance against official test suites and maintained >95% functional coverage across all verification targets.
